Comment pouvons-nous vous aider ?

Contactez Ariful ISLAM NAYAN à yanrioff@gmail.com.

Indiquez votre modèle de téléphone, la version de l’application et les étapes pour reproduire le problème. N’envoyez pas de mot de passe ni de fichier contenant vos données de santé.

Connexion santé

Dans Menu → Connexion santé, activez Apple Santé sur iPhone ou Health Connect sur Android. Vous pouvez autoriser séparément les pas, la distance et les calories actives. Vérifiez que des données existent dans votre application santé. Health Connect peut nécessiter une installation ou une mise à jour sur certaines versions d’Android.

Récupérer mes données

Avant une désinstallation ou un changement d’appareil, exportez une sauvegarde depuis le menu et conservez son mot de passe. Après réinstallation, importez ce fichier. Sans sauvegarde et mot de passe, les données locales perdues ne peuvent pas être restaurées par l’éditeur.

Supprimer mes données

Ouvrez Menu → Supprimer les données, lisez les explications, cochez les confirmations puis validez le dernier dialogue. Cette action efface les données de l’application sur l’appareil. Supprimez aussi vos sauvegardes exportées si nécessaire. Les données originales d’Apple Santé ou de Health Connect ne sont pas effacées par ARC365.

À propos des calories

Les calories issues de votre application santé sont prioritaires. À défaut, ARC365 utilise une estimation des séances si un poids corporel a été renseigné. Le temps d’effort exclut les pauses, les repos et le compte à rebours de préparation.
