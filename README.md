# ArcUp — site public

Présentation, assistance et confidentialité : https://pronosapp.github.io/arc365-public/

Mise à jour du 22 septembre 2026 : données Apple Santé étendues, limites Android, statistiques, connexion sans historique et sauvegardes locales.

Ce dépôt contient uniquement le site public. Il ne contient ni le code applicatif, ni des données utilisateur, ni des secrets. Il ne constitue pas une sauvegarde de l’application.

Les pages sont générées dans le projet ArcUp. La confidentialité partage sa source avec celle de l’application. Une publication du site ne met pas à jour le build TestFlight.

- `index.html` : présentation
- `support.html` : assistance
- `privacy.html` : confidentialité
- `style.css` : styles
